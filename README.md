📱 About the Project

Fitness & Health Tracker is a mobile application developed to make everyday fitness tracking easier and more accessible.

The application helps users maintain their fitness routines by tracking daily steps, recording workouts, monitoring calories burned, and viewing their daily and weekly progress.

I developed this project with the assistance of AI-powered development tools, using my own project requirements, ideas, implementation decisions, and testing.

🔥 Firebase Integration

The application uses Firebase services for backend functionality.

- Firebase Authentication: Google and Email/Password login.
- Cloud Firestore: Stores user profiles, workout records, fitness goals, and activity history.
- Firebase Realtime Database: Supports real-time workout and activity synchronization.

📲 Application Workflow

1. Register or sign in using Google or Email/Password.
2. Access the fitness dashboard.
3. Track daily activity and steps.
4. Record and manage workouts.
5. Set personal fitness goals.
6. Monitor daily and weekly progress.
7. View fitness statistics and analytics.

🚀 Getting Started

Prerequisites

- Android Studio
- Android SDK
- Java / JDK compatible with the project
- Firebase project
- Google AI Studio (for AI-assisted development)

Installation

1. Clone this repository:

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the downloaded project in Android Studio.

3. Add your Firebase configuration file:

app/google-services.json

4. Configure Firebase Authentication, Cloud Firestore, and Realtime Database.

5. Configure the required Firebase Gradle dependencies.

6. Configure your Gemini API key if Gemini functionality is used.

7. Sync Gradle and run the application on an Android emulator or physical device.

🔒 Security

- Firebase Authentication for user access.
- User-specific database access.
- Firestore security rules.
- Realtime Database security rules.
